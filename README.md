One commit message, 100 characters or fewer, for a bug fix that made
everything worse — an entry for the [Worst Fix Ever: Funniest Commit
Message](https://make.fun/bounty/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722)
bounty on [make.fun](https://make.fun), a $2 winner-take-all prize.

The entry fixes the symptom, not the cause: the alarm is silenced, the
fire is untouched — and the commit reports the quieter alarm as a win.

`main.py` writes the entry byte-identical to `entry.txt` into the output
directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). Deterministic,
no network, no randomness.
